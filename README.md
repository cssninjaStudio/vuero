# Digisquad - Boilerplate Vue3

### Quickstart

Use this repository to boostrap projects using Vue 3 composition API.

Clone this repo using degit in current directory

```bash
npx degit --mode=git git@github.com:digisquad-io/boilerplate-vuejs3.git <project-name>
```

### Included

- Vue3 Composition API
  - vue@next
  - vue-router@next
  - vue-toastification@next
  - @zhuowenli/vue-feather-icons
  - @fortawesome/fontawesome-free
  - axios
  - dayjs
- Scss + Bulma + Webfontloader
- Typescript + eslint + prettier + stylelint
- Docker ready (nginx + bitnami)
