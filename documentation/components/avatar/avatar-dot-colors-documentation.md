### Avatar dot colors

Avatar dots can have different colors. Set the `dotColor` prop to `primary`, `info`, `warning`, `danger` or `grey` to change the dot color. See code for more details about usage.

<!--code-->

```vue {2-4}
<template>
    <Avatar picture="/images/avatars/photos/7.jpg" size="medium" dot />
    <Avatar picture="/images/avatars/photos/8.jpg" size="medium" dot dotColor="primary" />
    <Avatar picture="/images/avatars/photos/11.jpg" size="medium" dot dotColor="info" />
    <Avatar picture="/images/avatars/photos/21.jpg" size="medium" dot dotColor="warning" />
    <Avatar picture="/images/avatars/photos/13.jpg" size="medium" dot dotColor="danger" />
    <Avatar picture="/images/avatars/photos/5.jpg" size="medium" dot dotColor="grey" />
</template>
```
