### Avatar

Vuero Avatars are rounded images used for media and personal pages. Avatar sizes can be controled with 'size' prop.  Available size prop values `small`, `medium`, `large`, `big` and `xl`. See code for more details about usage.

<!--code-->

```vue {2-4}
<template>
  <Avatar picture="/images/avatars/photos/7.jpg" size="small" />
  <Avatar picture="/images/avatars/photos/8.jpg" />
  <Avatar picture="/images/avatars/photos/11.jpg" size="medium" />
  <Avatar picture="/images/avatars/photos/21.jpg" size="large" />
  <Avatar picture="/images/avatars/photos/13.jpg" size="big" />
  <Avatar picture="/images/avatars/photos/5.jpg" size="xl" />
</template>
```
