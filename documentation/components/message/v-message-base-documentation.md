### V-Message

Vuero provides a `<V-Message />` component for messages that you can use
in your forms, for instance. The default message is displayed
on a grey background. Check the markup for more details.

<!--code-->

```vue
<template>
  <V-Message />
</template>
```

<!--/code-->

<!--example-->

<div class="field">
    <div class="control">
        <V-Message />
    </div>
</div>

<!--/example-->
