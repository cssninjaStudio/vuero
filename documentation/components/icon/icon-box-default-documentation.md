### Icon box

The Vuero `<IconBox />` component let you display icons in a fancy and colored way. Box sizes can be controled with the `size` prop. Available sizes are `small`, `medium`, `large`, `big` and `xl`. See code for more details about usage.

<!--code-->

```vue {2-4}
<template>
    <IconBox size="small">
        <i class="lnil lnil-vector-pen"></i>
    </IconBox>
    <IconBox>
        <i class="lnil lnil-vector-pen"></i>
    </IconBox>
    <IconBox size="medium">
        <i class="lnil lnil-vector-pen"></i>
    </IconBox>
    <IconBox size="large">
        <i class="lnil lnil-vector-pen"></i>
    </IconBox>
    <IconBox size="big">
        <i class="lnil lnil-vector-pen"></i>
    </IconBox>
    <IconBox size="xl">
        <i class="lnil lnil-vector-pen"></i>
    </IconBox>
</template>
```

<!--/code-->
