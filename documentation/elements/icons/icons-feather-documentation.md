### Feather Icons

Vuero is bundled with the `Feather Icons` javascript svg library.
Everyone likes Feather icons and they are widely used accross a large
variety of websites.
Please refer to the code example for more details about usage.

<!--code-->

```vue
<template>
  <!--Feather icon usage -->
  <i class="iconify" data-icon="feather:activity"></i>
</template>
```
